# Dataset notice

This notice applies to the two Yale MAT files included in this repository:

- `Yale_MissingRatio0.1_unbalanced.mat` (mean view missing rate about 10.1%; view rates about 4.85%, 10.30%, and 15.15%).
- `Yale_MissingRatio0.4_unbalanced.mat` (mean view missing rate 40%; view rates 20%, 40%, and 60%).

The development project did not retain authoritative upstream provenance, citation requirements, or redistribution terms for these exact files. The software license does not cover datasets. Users should follow the upstream dataset terms and include any required citation. This notice concerns the included Yale data only; the experiment code accepts other compatible multi-view MAT files. If redistribution is not permitted, remove the example MAT files from the public release and provide an authorized source or preparation instructions instead.
